## 📌 Technical Overview

This repository houses the high-fidelity web companion and component showcase for **Spendora**. It bridges UI/UX design specifications from Figma into a functional, component-driven web application using **React**, **TypeScript**, **Radix UI primitives**, and **Tailwind CSS**.

---

## ✨ Key Features

- **📊 Comprehensive Financial Cockpit**: Interactive run-rate summaries, spending category breakdowns, and real-time budget utilization meters.
- **🔄 Recurring Expense Management**: Dynamic subscription logging, billing cycle toggles (monthly vs annual), and upcoming renewal countdowns.
- **🎨 Accessible Component Architecture**: Built upon Radix UI primitives ensuring full keyboard navigation, screen reader compatibility, and WCAG accessibility standards.
- **🌙 Adaptive Dark / Light Theming**: Seamless appearance switching with custom design tokens.

---

## 🛠️ Technologies & Frameworks

- **Core Framework**: React 18 & TypeScript
- **Build Tool**: Vite 6
- **UI Components**: Radix UI Primitives, Lucide Icons, Shadcn UI patterns
- **Styling**: Tailwind CSS & PostCSS
- **Animation**: Motion (Framer Motion) & Canvas Confetti
- **Design System Reference**: [Spendora Hi-Fi Figma Canvas](https://www.figma.com/design/1ziEol0IUoeBvYMgunwviE/Hi-Fi-SpendoraSmart-Subscription---Spending-Tracker)

## 🚀 Quick Start

### Prerequisites
- Node.js (v18+) and npm / pnpm

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/snaimio/spendora-smart-subscription-spending-tracker.git
cd spendora-smart-subscription-spending-tracker

# Install dependencies
npm install

# Start development server
npm run dev
```
